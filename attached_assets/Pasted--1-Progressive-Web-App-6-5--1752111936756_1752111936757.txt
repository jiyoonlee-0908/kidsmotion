키즈모션 시스템 기술 프로토콜 (특허 출원용)
1. 시스템 개요
키즈모션은 아동의 운동 능력을 측정하는 Progressive Web App으로, 6단계 독립적인 물리적 테스트(5초, 15초, 30초, 60초, 180초, 360초)를 통해 실시간 Garmin Rally RS200 파워 페달 데이터를 BLE(Bluetooth Low Energy)로 수집하고 분석하는 시스템입니다.

// server/supabase-garmin.ts 라인 47-89
export async function saveGarminData(garminData: {
  sessionId: number;
  userDisplayName: string;
  power: number;
  cadence: number;
  leftBalance: number;
  rightBalance: number;
  pedalingSmoothness: number;
  torqueEffectiveness: number;
}) {
  try {
    const koreaTime = new Date(new Date().getTime() + (9 * 60 * 60 * 1000));
    
    const { data, error } = await supabase
      .from('garmin_data')
      .insert([{
        session_id: garminData.sessionId,
        user_display_name: garminData.userDisplayName,
        power: garminData.power,
        cadence: garminData.cadence,
        left_balance: garminData.leftBalance,
        right_balance: garminData.rightBalance,
        pedaling_smoothness: garminData.pedalingSmoothness,
        torque_effectiveness: garminData.torqueEffectiveness,
        timestamp: koreaTime.toISOString()
      }])
      .select()
      .single();
    return data;
  } catch (error) {
    console.error('Error saving garmin data:', error);
    return null;
  }
}

5.2 파워 데이터 조회 API
// server/routes.ts 라인 144-180 (예상)
app.get("/api/stage-intervals/:displayName", async (req, res) => {
  try {
    const displayName = req.params.displayName;
    const { data: intervals, error } = await supabase
      .from('stage_intervals')
      .select('*')
      .eq('user_display_name', displayName)
      .order('sequence_number', { ascending: true });
      
    if (error) {
      return res.status(500).json({ message: "Error fetching stage intervals", error });
    }
    
    res.json(intervals || []);
  } catch (error) {
    res.status(500).json({ message: "Error fetching stage intervals", error });
  }
});

6. 데이터 흐름도
[측정시작] → [개인정보입력] → [Supabase participants 테이블 저장]
     ↓
[가민페달 BLE 연결] → [실시간 데이터 수집] → [Supabase garmin_data 테이블 저장]
     ↓
[6단계 테스트 진행] → [단계별 집계] → [Supabase stage_intervals 테이블 저장]
     ↓
[웹앱 API 호출] → [중복 제거된 사용자 검색] → [파워 데이터 조회] → [보고서 생성]
7. 기술적 혁신 포인트
실시간 BLE 데이터 수집: Garmin Rally RS200과 Web Bluetooth API를 통한 실시간 파워 데이터 수집
이중 데이터베이스 구조: 실시간 데이터(garmin_data)와 집계 데이터(stage_intervals) 분리로 성능 최적화
소수점 정밀도 지원: NUMERIC(8,2) 타입으로 250.53W, 51.25% 등 정밀한 측정값 저장
자동 중복 제거: API 레벨에서 사용자 중복 제거로 데이터 무결성 보장
웹앱 자동 연동: 태블릿에서 수집한 데이터를 웹앱에서 자동으로 불러와 보고서 생성
이 시스템은 아동의 운동 능력을 정밀하게 측정하고 분석하는 혁신적인 기술 플랫폼으로, 특허 출원에 충분한 기술적 독창성을 가지고 있습니다.
