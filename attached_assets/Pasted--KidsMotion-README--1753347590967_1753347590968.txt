2-1. Percentile Scaling 알고리즘
ts
복사
편집
const getScalingExponent = (age: number): number => {
  if (age <= 9) return 0.75;
  if (age <= 13) return 0.72;
  return 0.67;
};
문제점: 참고 논문이나 출처 명시 없이 "과학적"이라고 표현

제안: 근거 논문 링크 또는 "based on ACSM youth scaling recommendations" 등 주석으로 출처 보강 필요

대안: scalingExponent를 외부 설정값으로 추출 가능하도록 하면 추후 보정 용이
