#	원인	증상	해결법
① API 키 노출 방식 오류	Replit에 환경변수 등록 안 함, 코드에 직접 노출	콘솔: “Invalid key” 또는 401 Unauthorized	Secrets 설정에 OPENAI_API_KEY 등록
② 환경변수 이름 오탈자	코드에서는 process.env.OPENAI_KEY인데, 실제는 OPENAI_API_KEY 등 불일치	undefined 에러	.env 또는 Secrets에서 이름 정확히 일치시킬 것
③ 서버 코드에서 키를 프론트에 노출	브라우저 콘솔에서 키를 볼 수 있음 = 매우 위험	API 호출 실패 또는 보안 경고	프론트 → 서버 경유 → 서버가 OpenAI API 호출하는 구조로
④ CORS 또는 fetch 방식 오류	클라이언트 fetch 직결 시 인증 헤더 오류	콘솔: CORS 차단, 헤더 누락	반드시 서버(백엔드)에서 호출하도록 구현
⑤ 유효하지 않은 키 or 사용량 한도 초과	OpenAI API 사용량 대시보드에 아무것도 안 찍힘	콘솔에 401 또는 empty result	OpenAI Usage 대시보드에서 확인

✅ 해결 절차 요약 (순서대로 점검)
🔧 1. Replit Secrets에 키 등록했는지 확인
Replit의 .env가 아니라 Secrets 탭에서 등록해야 합니다:

Replit IDE 오른쪽 상단의 🔐 “Secrets” (또는 Environment Variables)

키: OPENAI_API_KEY
값: sk-proj-... (전체 붙여넣기)

저장

❗ 이걸 안 하면 process.env.OPENAI_API_KEY가 undefined가 됩니다.

🧠 2. 서버 코드 구조 예시 (/api/summary)
js
복사
편집
// Express 예시
import express from 'express'
import fetch from 'node-fetch'

const app = express()
app.use(express.json())

app.post('/api/summary', async (req, res) => {
  const { prompt } = req.body
  const apiKey = process.env.OPENAI_API_KEY

  const response = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'gpt-4o',
      messages: [{ role: 'user', content: prompt }],
    }),
  })

  const data = await response.json()
  res.json({ result: data.choices[0].message.content })
})

키가 유출되면 누군가가 수천 달러를 쓸 수도 있어요—반드시 서버에서만 사용하세요.
